## 🛠 Installation · التثبيت

1. Run `FireProtectionDigitalTwin-Setup.exe`. If Windows shows **“Windows protected your PC”**, click **More info → Run anyway** (the program is safe; it is not yet signed with a paid certificate).
   شغّل ملف التثبيت. إذا ظهرت رسالة **«Windows protected your PC»** اضغط **More info ثم Run anyway**.
2. Choose the language, accept the license agreement, click **Install → Finish**.
   اختر اللغة، ووافق على اتفاقية الترخيص، ثم **Install ← Finish**.
3. The program starts with a **14-day trial**. To activate a monthly or yearly subscription click 🔑, send your **Machine ID** to ASFAN and load the `.lic` file you receive.
   يبدأ البرنامج بنسخة **تجريبية 14 يوماً**. للتفعيل اضغط 🔑، وأرسل **معرّف الجهاز** إلى أصفان، ثم حمّل ملف `.lic` الذي يصلك.

Installed copies show a notice automatically when a new version is published here.
تُظهر النسخ المثبّتة تنبيهاً تلقائياً عند نشر إصدار جديد هنا.
